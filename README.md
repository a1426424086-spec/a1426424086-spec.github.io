# 食光 · 私人食谱

手机配餐工具，支持可编辑食材库、每天的餐次记录、营养汇总和历史查询。

所有运行文件均包含在此目录内，可部署到普通 HTTPS 静态网站根目录，配餐功能不需要后端或 ChatGPT 账号。好物推荐使用本站 content/recommendations.json 和 recommendations/ 图片目录，随 GitHub Pages 一起发布，不需要云数据库或管理登录。内容在打开、切回页面及每分钟联网检查时更新。可直接将推荐食品及每100克营养导入本机食材库；重复导入不会覆盖自己改过的值。

配餐数据保存在当前设备、当前浏览器的网站存储中，不会自动跨设备同步。本版按要求不展示导入导出入口；不同手机、浏览器或网址的数据独立，请勿清理网站存储。

蛋白折算为用户自定义估算规则：肉、蛋、奶 100%，蔬菜、水果 50%，其余 80%，支持逐项修改，不表示人体实际吸收率。

## GitHub Pages

将本目录的应用文件放在仓库根目录，在 Settings → Pages 选择 Deploy from a branch → main → /(root)。本版本需要部署在网站根路径；不要将它放在二级项目路径下。
