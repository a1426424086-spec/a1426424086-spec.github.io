# 食光 · 私人食谱

手机配餐工具，支持可编辑食材库、每天的餐次记录、营养汇总和历史查询。

所有运行文件均包含在此目录内，可部署到普通 HTTPS 静态网站根目录，不需要后端、数据库或 ChatGPT 账号。

配餐数据保存在当前设备、当前浏览器的网站存储中，不会自动跨设备同步。清理网站数据或换手机前，请在应用内导出备份；更换网址后可导入原备份。

蛋白折算为用户自定义估算规则：肉类 100%、面包 80%、其余 50%，支持逐项修改，不表示人体实际吸收率。

## GitHub Pages

将本目录的应用文件放在仓库根目录，在 Settings → Pages 选择 Deploy from a branch → main → /(root)。本版本需要部署在网站根路径；不要将它放在二级项目路径下。
