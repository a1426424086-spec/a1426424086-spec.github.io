## 更新内容

可以直接把食品名称、截图、链接和包装营养表发给 Codex，由 Codex 修改并发布。也可以自己登录 GitHub：

1. 在仓库根目录 `recommendations/` 上传截图，支持 PNG、JPG、JPEG、WebP，每张不超过 8 MB。文件名使用英文、数字、短横线、下划线。替换图片时换一个新文件名，例如 `oat-20260925.png`，防止旧缓存。
2. 修改 `content/recommendations.json`，在 `items` 中加入条目。下面只是格式示例，数值和链接须换成真实资料，不能原样发布：

```json
{
  "version": 1,
  "items": [
    {
      "id": "daily-bread",
      "title": "食品名称",
      "category": "主食",
      "link": "https://example.com/food",
      "images": ["/recommendations/bread-20260925.png"],
      "updatedAt": "2026-09-25",
      "nutrition": {"carbs": 40, "protein": 10, "fat": 5, "factor": 80}
    }
  ]
}
```

3. `carbs` 碳水、`protein` 包装蛋白质、`fat` 脂肪都是每 100 克的克数，缺数据先核对包装，不要填猜测值。`factor` 是 100、80、50 中的一项，可省略，省略时按肉蛋奶100%、蔬菜水果50%、其余80%估算。
4. 热量自动按 `碳水×4 + 全部蛋白质×4 + 脂肪×9` 计算；有效蛋白按包装蛋白质乘折算比例计算。它是自定义估算，不代表实际人体吸收率。
5. 分类可用：主食、肉类、蛋类、蔬菜、水果、豆类及豆制品、奶制品、其他。同一食品修改时保留 `id`；新增食品使用新的 `id`。每项 1–5 张截图，最新日期排前面，同一天按文件顺序。
6. 演示样品可显式添加 `"nutritionSource": "example"`。页面会标明“示例营养 · 非商品包装值”，导入后的名称也会保留“示例营养”。正式商品请核对包装后使用真实值；不要将示例当作实测数据。
7. 提交到 `main` 后等待 GitHub Pages 发布，打开原网址核验。GitHub 表示发布可能需要约 10 分钟。只是修改本地文件不会更新手机上的公开网站。

## 导入与下架

- 点击商品图片打开条目中的商品链接，链接不单独占一个按钮；营养和导入操作保留在图片下方。

- 点「导入食材库」，食品和营养存入当前浏览器的本机食材库，排在上方，之后可以改数值并配餐。
- 已导入或同名食品不会重复添加。后续推荐更新不会覆盖用户自己调整的食品。
- 下架时从 `items` 删除对应条目。已导入的本机食品仍保留。公开仓库中的历史提交和曾公开图片仍可能被访问，不把草稿、账号或私人资料放进去。
- 好物推荐会在打开、切回页面、点击刷新及每分钟联网检查时读取本站最新文件；部署或缓存更新期间可能有延迟。读取失败会保留本次打开时已有的列表并提示重试，不把错误显示为「没有好物」。

## 公开参考食谱

`public/content/recipes.json`（发布后为 `content/recipes.json`）保存10套参考食谱，可在“食谱夹 → 参考食谱”查看、存入自己的食谱夹或选择日期使用。参考内容会随网站发布更新，个人保存的副本保留原来的内容。

当前共有A–J十套食谱：工作日3套、居家3套、吃得开心4套。每类按碳水从高到低排列；高碳低脂时热量较高，低碳高脂时热量较低，均在1300–1500千卡内。有效蛋白按当前需求配置为109.375–115.625克，每餐均含碳水、蛋白质、脂肪，多数餐次配蔬菜或水果。所有营养显示整数，计算保留精度；方便食用的好物可融入三类日常搭配。工作日早餐以冲泡麦片、全麦面包为主，鸡蛋可提前煮好；午晚餐方便分装备餐。居家搭配简单炒煮，开心组增加口味变化。天然食材尽量用50克倍数，米和燕麦可用25克，坚果和油用5克倍数。天然食材按生重可食部分、米和燕麦按未煮干重，包装商品按成品重量。天然食材成分来自USDA FoodData Central普通食物参考；推荐商品使用用户给出的每100克数值。热量统一使用碳水4、全部蛋白4、脂肪9的近似系数，可能与成分表列出的能量不同。

山姆混合坚果采用用户给定数值，尚未获得对应完整营养标签照片。三款未填写营养的碱水面包未用于定量食谱，蓝莓示例数据未用于真实配餐。配料中的鸡蛋每个暂按去壳50克，优先实际称重；菜名下列出蛋数、油量和原料克数，不再叠加菜肴成品重量。盐和无热量调味适量，额外糖及酱料需另计。

参考食谱不代表每位访客都适合1300–1500千卡，应按自己的需求调整。蛋白质营养建议通常指总蛋白，本应用的“有效蛋白”为用户自定义折算列。

参考食谱详情的“修改这份食谱”可以改名称、增删食材、调整克数，保存到当前设备的“我的食谱”；公共原版不会被访客改写。个人食谱可继续编辑。变更某餐原料后，移除该餐旧菜式说明，防止鸡蛋数量和做法与新原料矛盾。

商品图可选用 `imagePosition`（0–100，纵向位置百分比）调整方形展示区域，原图保留。当前为产品主体取景，点击图片仍打开商品链接。
