# 食光 · 微信小程序

由网页版「食光 · 私人食谱」（https://a1426424086-spec.github.io/ ）移植的微信原生小程序：按日期、按时间记录饮食，自动计算营养，按日期回看。数据只存在手机本机。

## 功能

| 页面 | 内容 |
| --- | --- |
| 配餐（首页） | 前一天/后一天/选日期；第一餐、第二餐、第三餐、加餐；每条记录有时间（点时间可改），点食材可改用量、换餐次、删除；当日热量、碳水、蛋白质、有效蛋白、脂肪合计；存入食谱夹、清空当日 |
| 添加食材 | 搜索 + 分类筛选；选餐次、时间、用量（鸡蛋/苹果/香蕉等可按“个/根”记）；实时预览本次营养；可连续添加 |
| 统计 | 近 7 / 30 天每日热量柱状图、有记录日的日均营养、餐次热量占比；历史记录列表，点任一天直接打开 |
| 食材库 | 29 项默认食材（与网页版一致）；新增、编辑、删除；热量和有效蛋白自动计算 |
| 好物推荐（食材库顶部进入） | 9 款推荐食品，商品图、每 100 克营养、每份重量；点图片复制商品链接，长按放大；「导入食材库」后可按份记录；同 ID 或同名已存在时不重复导入、不覆盖 |
| 食谱夹 | 我的食谱 + 10 套参考食谱（工作日/居家/吃得开心）；查看详情，选日期一键套用（已有记录会先确认替换） |

计算规则与网页版一致：热量 = 碳水×4 + 蛋白质×4 + 脂肪×9；有效蛋白 = 蛋白质 × 折算比例（默认肉蛋奶 100%、蔬果 50%、其余 80%，是自定义估算，不代表实际吸收率）。

数据规则：每条记录保存当时的营养快照。修改食材只同步今天及以后的记录，过去的记录保持原样；删除食材不影响已有记录和食谱。

## 在微信开发者工具中导入预览

1. 安装「微信开发者工具」稳定版：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html ，用微信扫码登录。
2. 首页选「小程序」→「导入」（或左上角 项目 → 导入项目）。
3. 目录选择本仓库里的 **`miniprogram` 文件夹**（不是仓库根目录）。
4. AppID：
   - 只在电脑模拟器里看：选「测试号」，或保持 `project.config.json` 里的 `touristappid`（游客模式）。
   - 要在手机上扫码预览：需要测试号或自己的 AppID（测试号可在 https://developers.weixin.qq.com/sandbox 免费申请），填入后点「确定」。
5. 不需要云开发、不需要服务器，导入后自动编译，左侧模拟器即可使用。
6. 手机预览：工具栏「预览」→ 用微信扫二维码；或「真机调试」。

查看/清空数据：调试器 → Storage 面板中的 `sg-*` 键；工具栏「清缓存 → 清除数据缓存」会清空所有记录并恢复默认食材。

## 目录结构

```
app.js / app.json / app.wxss   全局入口、页面与 tab 配置、全局样式（深色 + 米金色）
utils/store.js                 本机存储：食材库、每日记录、食谱
utils/nutrition.js             营养计算、分类、餐次
utils/date.js                  日期工具
data/foods.js                  默认食材（取自网页版）
data/recipes.js                参考食谱（取自网页版 content/recipes.json）
data/goods.js                  好物推荐（取自网页版 content/recommendations.json）
images/goods/                  商品图：按网页版 imagePosition 裁成正方形，压缩到 480×480（共约 660KB）
pages/goods                    好物推荐
pages/day                      配餐（首页）
pages/pick                     添加食材
pages/stats                    统计
pages/foods                    食材库
pages/food-edit                新增/编辑食材
pages/recipes                  食谱夹
pages/recipe                   食谱详情
```

存储键：`sg-meta`、`sg-foods`、`sg-recipes`、`sg-dates`（有记录的日期索引）、`sg-day:YYYY-MM-DD`（每天一条，避免单键超过 1MB）。

## 暂未包含

- 好物推荐目前随小程序打包（整个项目约 0.9MB，主包上限 2MB）。网页版更新推荐后，需要重新生成 `data/goods.js` 和图片再发版；如要自动联网更新，可改为读取 `https://a1426424086-spec.github.io/content/recommendations.json`，需在小程序后台把该域名加入 request 合法域名。
- 小程序不能直接打开抖音等外部商品页，所以点图片是复制链接。
- 照片记录、食谱编辑器、云端备份/跨设备同步。
- tabBar 图标（目前为纯文字 tab）。
