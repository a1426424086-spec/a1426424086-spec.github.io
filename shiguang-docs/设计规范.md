# 食光小程序 · 设计规范 v1「暗夜金」

- 用户选定方向：A 暗夜金（2026-11-01，用户原话「A 暗夜金」；起因「ui界面不好看，不够高端」）。
- 代码正本：网页版仓库 `miniprogram/`，分支 `cc-shiguang-launch`，worktree `~/Documents/ChatGPT/cc-worktrees/shiguang-launch`。
- 黄金样例：`app.wxss` + `pages/day`（配餐首页），由 Claude 写。其余页面照此改。

## 1. 一句话
深色、克制、像高级餐厅的菜单：**去掉框，靠留白和细线分组；数字用衬线体；金色只用来点题**。

## 2. 颜色（写在 `app.wxss` 的 `page` 上，页面只用变量）

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#0F0F0E` | 页面底色、导航栏、tabBar |
| `--surface` | `#181715` | 只用于弹层（sheet）、输入框底 |
| `--line` | `#26241F` | 默认细线（列表分隔） |
| `--line-strong` | `#3A362E` | 区块上下的强调线、按钮描边 |
| `--text` | `#EDE6D6` | 正文 |
| `--text-soft` | `#8C8471` | 次要文字、单位 |
| `--text-faint` | `#5E584C` | 占位、未选中 tab |
| `--gold` | `#C9A96E` | 点题：区块标题、选中态、进度、主按钮 |
| `--gold-soft` | `#8F7A52` | 圆环第二段、弱化金色 |
| `--ink` | `#14130F` | 金色底上的文字 |
| `--danger` | `#D98C7A` | 删除、清空 |

禁止：大块米色/亮色底卡片；渐变（圆环除外）；阴影；任何新颜色。

## 3. 字体
- 正文：PingFang SC，28rpx，行高 1.5。
- **数字**（热量、克数、时间、日期、百分比）：`.num` = `"Songti SC", "STSong", "Noto Serif", Georgia, serif`，`font-weight: 400`。安卓没有宋体也会落到衬线西文字体，数字效果一致。
- 中文**不用**衬线体（安卓会退回黑体，两端不一致）。品牌字「食 光」例外，可用 `.num` 字体族 + 字距。
- 字重只用 400 / 500，不用 600 以上。
- 区块标题（小标签）：`.label` = 22rpx、`letter-spacing: 4rpx`、金色。例：「第一餐 · 08:00」「每日热量」。
- 页面大标题：40rpx、500。每页最多一个，不和导航栏重复。

## 4. 布局
- 页边距 40rpx（`.wrap`）。区块之间 56rpx。
- **列表不用卡片**：每行之间 1rpx `--line`；行高至少 96rpx（可点区域）。整组上下用 `--line-strong`。
- `.card` 保留类名但改为「无底色、无边框，仅上方一条 `--line-strong`」，避免改动所有 wxml。
- 圆角：按钮、chip 用 999rpx；弹层顶部 32rpx；其余直角。

## 5. 组件
- **主按钮** `.btn`：金色底、`--ink` 字、高 88rpx、500。一页最多一个。
- **次按钮** `.btn.ghost`：透明底、1rpx `--line-strong` 描边、`--text`。`.btn.danger`：透明、`--danger` 字、描边 `#4A322C`。
- **chip**（分类筛选）：无边框；未选 `--text-soft`；选中 `--gold` 且下方 4rpx 金色短线（伪元素，宽 24rpx 居中）。
- **分段切换** `.seg`：去掉胶囊底；两项文字，选中 `--text` + 下方 2rpx 金线，未选 `--text-faint`；整条下方 1rpx `--line`。
- **搜索/输入框**：`--surface` 底、无边框、圆角 999rpx（搜索）/ 12rpx（表单）。
- **点按反馈**：可点元素加 `hover-class="press"`，`.press { opacity: .6 }`。
- **营养总览**（配餐首页、统计页日均）：左侧圆环（`conic-gradient`，三段按热量占比：碳水 `--gold`、蛋白 `--gold-soft`、脂肪 `--line-strong`，内圈挖空成 `--bg`），右侧大号热量数字 72rpx `.num`；下方一行四项（碳水/蛋白质/有效蛋白/脂肪），上下 `--line-strong`，数字 `.num` 36rpx。没有目标值，不显示「目标」。
- **柱状图**（统计）：柱子 `--line-strong`，当天 `--gold`；柱宽 ≤ 28rpx（细柱更高级）；数值 `.num` 20rpx `--text-soft`。
- **进度条**（餐次占比）：轨道 2rpx `--line`，进度 2rpx `--gold`。

## 6. 导航与 tabBar
- `app.json`：`navigationBarBackgroundColor` `#0F0F0E`；`backgroundColor` `#0F0F0E`；tabBar `backgroundColor` `#0F0F0E`、`color` `#5E584C`、`selectedColor` `#C9A96E`、`borderStyle` `black`。
- 页面标题去掉「食光 · 」前缀：配餐 / 统计 / 食材库 / 食谱夹 / 添加食材 / 食材 / 食谱详情。
- tabBar 图标：本版不做（需另出 PNG），列入下一轮。

## 7. 配餐首页（黄金样例要点）
- 顶部一行：左「食 光」（衬线、字距 8rpx、`--text-soft`），右日期切换 `‹ 11.01 周日 ›`（`.num`）。删掉「今日配餐」大标题、「私人食谱」「爱上更棒的自己」「记录自动保存在本机」（最后一句移到页尾提示）。
- 非今天时，日期下方小字金色「回到今天」。
- 营养总览见第 5 节。
- 每个餐次：`.label`「第一餐」+ 右侧 `.num` 小计千卡 + 右端「＋」（64rpx 圆形 1rpx `--line-strong` 描边）。下面是食材行：时间（`.num` `--gold-soft`）｜名称 + 用量（`--text-soft` 24rpx）｜千卡（`.num`）。空餐次只显示一行 `--text-faint`「还没有记录」。
- 底部两个次按钮「存入食谱夹」「清空当日」。

## 8. 验收（截图核对）
- 每页一张：配餐（有数据 / 空日）、统计（7 天 / 30 天）、食材库、添加食材（含选用量弹层）、食材编辑、食谱夹、食谱详情。
- 检查：没有残留的米色卡片、灰绿色、胶囊描边 chip；数字都是衬线体；没有标题重复；长食材名单行省略不挤压千卡列；功能不变（只改样式和少量 wxml 结构，不改 js 逻辑和存储）。

## 3. 字体
- 数字 `.num`：`ui-serif, "New York", "Times New Roman", serif`，`font-variant-numeric: lining-nums tabular-nums`（等高等宽，表格对齐）。大数字 600，小数字 400–500。
- 大标题（问候语、面板标题）：`"Songti SC", "STSong", "Noto Serif SC", "Source Han Serif SC", serif`，700。

## 4. 版式

## 5. 交互与使用逻辑（首页）
- 一周日期条：按周横滑翻页；点哪天看哪天；有记录的日子下方 8rpx 小点；每月 1 号上方显示「N月」金色；今天金字；选中金底。
- 点顶部日期「11月5日 周四 ⌄」弹月历：翻月、选任意一天（含未来）、「今天」按钮。不是今天时右侧出「回到今天」胶囊。
- 营养卡片上左右滑也能换天（只在这张卡片上，避免和食物左滑删除冲突）。
- 点一餐：有记录则展开/收起（同时只展开一餐）；没记录则去添加。空餐且前一天同一餐有记录时显示「照昨天」，一键照搬，可撤销。
- 点一样食物：底部面板，份量 −/+（克：<50 克每次 5 克，否则 10 克；按「个」等单位记的每次 0.5 个），也可点数字直接输入；换餐次（分段控件）；改时间；删除 / 完成。
- 食物左滑露出「删除」，点删除即删，底部提示「已删除 xx · 撤销」3.2 秒。
- 往下滑过 60px，顶部出现毛玻璃条，居中显示问候语 + 日期。
- 「存入食谱夹」「清空这一天」放页尾卡片；清空仍弹确认。
- 动效：按下 0.1s 变暗/缩到 0.9–0.97；展开、面板、标题条 0.3–0.42s `cubic-bezier(.32,.72,0,1)`；圆环 0.9s 画出。

# v3.1「顺滑」（2026-11-04，在 v3 基础上只加动效，不改视觉和功能）

- 用户原话：「再把动画做的丝滑点ui洁面的交互提升一下」。原型 `原型-动效-20261104.html`（现在 / 改后 对比）；用户在 A 顺滑 / B 跟手手势 / C 触感 三组里**只选了 A**。B、C 不做（不加下拉关面板、营养卡跟手、月历滑动翻月、左滑看速度 / 拉到底删除、震动）。
- 依据：`apple-design` 技能（按下即反馈、从当前值出发、同路进出、减弱动态效果时只淡入淡出）。

## 1. 动效参数（全站统一）
| 名称 | 值 | 用在 |
|---|---|---|
| 主曲线 `--ease` | `cubic-bezier(.32,.72,0,1)` | 面板、展开、换天、增删行、滑块 |
| 按下 | 立即（`hover-start-time="0"`），松手 0.1s 后撤销（`hover-stay-time="100"`），撤销时 0.15s 淡回 | 所有可点元素 |
| 按下样式 | 列表行：底色 `rgba(245,239,227,.05)`；圆按钮：缩到 0.86–0.9；大按钮：缩到 0.97 + 不透明度 0.85；文字 / 胶囊：不透明度 0.6 | |
| 底部面板 | 进 0.42s、出 0.3s，遮罩淡入淡出 0.3s；三处（首页、食谱详情、添加食材）同一套 | |
| 一餐展开收起 | 高度 0.32s + 内容淡入下移 12rpx | 首页 |
| 换天 | 内容从滑动 / 前进方向平移 48rpx + 淡入，0.34s；往后一天从右边来，往前一天从左边来 | 首页 |
| 圆环 / 千卡 | 首次进入从零画 0.9s；之后（换天、加删食物、回到首页）从**屏幕上当前值**过渡到新值 0.6s；千卡数字逐帧跟圆环同曲线（ease-out cubic） | 首页 |
| 新增行 | 高度从 0 展开 + 淡入 + 下移 12rpx，0.4s | 首页、食谱详情 |
| 删除行 | 高度收到 0 + 淡出，0.28s；一餐最后一样删掉时整餐同时收起 | 首页、食谱详情 |
| 分段控件 | 选中底块 0.3s 平移到新位置（不再瞬间跳） | 面板「放在」、食谱夹顶部、蛋白折算比例 |
| 加入食物 | 不弹系统「✓ 已加入」大提示；面板收起，所点那行的 ＋ 变金底 ✓ 0.9s，底部「已加入 N 项」上滑出现（0.42s），每次加入数字放大一下（0.34s） | 添加食材 |

## 2. 减弱动态效果
`@media (prefers-reduced-motion: reduce)`：换天、增删行、数字跳动只保留淡入淡出（不平移、不缩放）；面板仍上滑（系统同样做法）。
